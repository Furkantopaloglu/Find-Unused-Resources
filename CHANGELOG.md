## 0.0.3

- Added inline delete button (trash icon) for each unused item in the tree view.
- One-click deletion of unused assets from disk.
- One-click removal of unused packages from pubspec.yaml.
- One-click deletion of unused classes and methods from source files.
- Supports both brace-block (`{ }`) and arrow function (`=>`) Dart syntax for class/method deletion.
- All delete actions require user confirmation via modal dialog.
